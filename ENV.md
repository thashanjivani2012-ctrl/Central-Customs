# Environment variables

Set these on the Railway service. Never commit real values.

Required: TOKEN, APP_ID, MONGO_URI (or MONGO_URL). Optional: ROBLOX_COOKIE (needed for /payment).

Channels: SUPPORT_PANEL_CHANNEL_ID, ORDER_PANEL_CHANNEL_ID, WELCOME_CHANNEL_ID,
TICKET_FILES_CHANNEL_ID, TICKET_TRANSCRIPTS_CHANNEL_ID, PROMOTE_LOG_CHANNEL_ID,
DEMOTE_LOG_CHANNEL_ID, INFRACTION_LOG_CHANNEL_ID, ORDER_LOG_CHANNEL_ID,
REVIEW_CHANNEL_ID, STAFF_FEEDBACK_CHANNEL_ID, QC_CHANNEL_ID

Roles: STAFF_ROLE_ID, DESIGN_ROLE_ID, QC_ROLE_ID, CLAIM_ROLE_ID_1, CLAIM_ROLE_ID_2

Support tickets: SUPPORT_GENERAL_CATEGORY_ID, SUPPORT_GENERAL_ROLE_ID,
SUPPORT_HIGH_RANK_CATEGORY_ID, SUPPORT_HIGH_RANK_ROLE_ID

Order tickets, one category and one role per type (LIVERYELS, GRAPHIC, DISCORD,
CLOTHING, PHOTOGRAPHS, BOTSERVICES): ORDER_<TYPE>_CATEGORY_ID, ORDER_<TYPE>_ROLE_ID

Other: ORDER_LINK_URL (the Order button in the welcome message)
